Platecrafted™

My girlfriend asks me to make a grocery list every week! I got tired of the Sunday evening ritual — what do I eat this week? How do I cook it? What do I even buy?

Platecrafted fixes that. Search meals, filter by ingredient or cuisine, watch how to cook them, and save your favourites so you stop finding the same recipe from scratch every time.

Built on the MEAN Stack

MongoDB

Stores your saved meals in a cloud Atlas cluster — no SQL, just documents.

Express.js

Lightweight REST API sitting between Angular and MongoDB, handling favourites.

Angular

The frontend — signals, routing, reactive forms, and a component-driven UI.

Node.js

Runs the Express server. The whole backend is a single index.mjs file.

Monorepo Architecture

  • Frontend Angular app — talks to both the backend API and TheMealDB directly
  • Backend Express REST API — connects to MongoDB Atlas to persist your saved meals
  • External TheMealDB — free public API, no key needed, thousands of recipes

Philosophy

Software should genuinely make life easier — automating the tedious so your thinking is freed up for more important things. Platecrafted is a small proof of that: one less decision to make each week, handled quietly in the background (God bless!).
